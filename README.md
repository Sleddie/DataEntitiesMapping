# DataEntitiesMapping

The project of **classes library** for data-to-object mapping using XML-syntaxbased on XML configuration of properties-to-fields matching.

### Technologies used
* C#
* .NET Framework 3.5
* System.Xml.Linq

### Installation and setup
1. Clone the repository;
2. Open in Visual Studio;
3. Build project as library.

### Usage
Add reference to the DataEntitiesMapping.dll in your project.
